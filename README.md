# ✦ Shristi Bajracharya — Portfolio

> An interactive personal portfolio built to showcase my journey, projects, skills, and the things I'm learning along the way.

This is my personal developer portfolio, designed and built from scratch with a focus on **interactive experiences, smooth animations, modern UI, and thoughtful development**.

Rather than being just a collection of projects, this website is an ongoing representation of my journey as a developer.

---

## 🚀 Tech Stack

* **Next.js** — React framework
* **TypeScript** — Type-safe development
* **Tailwind CSS** — Styling
* **shadcn/ui** — UI components
* **GSAP** — Advanced animations
* **Lenis** — Smooth scrolling
* **Lucide React** — Icons
* **Three.js / React Three Fiber** — Interactive 3D experiences
* **Vercel** — Deployment

## 🛠️ Getting Started

Clone the repository and install the dependencies:

```bash
git clone <repository-url>

cd shristi-portfolio

npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

The application will automatically update as you make changes.
